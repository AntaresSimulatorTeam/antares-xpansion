# Update Ubuntu support to 22.04

## Accepted [24 Feb. 2025]

## Context

As of February 2025, we are supporting Ubuntu 20.04. The core team was using 20.04 for development and testing.
As of March 2025 Github actions don't support Ubuntu 20.04
anymore. [20.04 Brown out](https://github.blog/changelog/2025-01-15-github-actions-ubuntu-20-runner-image-brownout-dates-and-other-breaking-changes/)
Core team members are also migrating to using 22.04 for development and testing. We should update our support to 22.04.

## Decision

Update Ubuntu support to 22.04

## Consequences

Update github actions to use 22.04
Update documentation.
